# 《影之刃零》恶毒角色替换 Mod

把《碧蓝航线》的恶毒（Le Malin）带进《影之刃零》。恶毒超可爱！ᗜˬᗜ

本仓库整理制作源码、工具和开发经验。玩家安装包通过网盘单独分享。

## 已完成的内容

- 白色与黑色两套服饰，黑色采用最终确认的哑光丝袜配色。
- 原游戏动作重定向，自然眨眼、自动表情和小幅眼神移动。
- 双辫重力、身体碰撞，软耳与竖耳两种模式，以及左右耳碰撞。
- 一般与宝石两种眼睛效果。
- 背部武器显隐及后移调节，包含腰后的工具小刀。
- F8 打开右侧设置面板，使用游戏自带字体、贴图和样式资源。
- 独立可选的恶毒战斗语音包，保留剧情与对话语音。

## 玩家使用

当前角色发布包为 **0.2.0**，采用已验收的 `0.2.0-dev.30` 构建。语音发布包为 **0.1.0**，采用 `0.1.0-dev.3` 构建。包内保留原构建文件名，方便核对实际版本。

关闭游戏，将角色包中的 `ProjectPBZ` 文件夹合并到游戏根目录。进入游戏后按 **F8** 调整设置。语音包另行安装，需要游戏使用**中文语音**。

完整安装、更新、卸载方法与默认设置见 [玩家说明](docs/玩家说明.md)。

## 当前边界

- 保留原游戏的主体动作，手持武器握点有少量偏差。
- 头发配置身体碰撞，世界碰撞、辫子自碰撞和武器碰撞未覆盖。
- 自动表情按时间变化，眼神移动会在移动时回正，尚未联动锁定目标。
- 日光受光采用当前接受的底色补偿，丝袜薄透感通过不透明底色与表面参数模拟。
- 游戏更新、其他主角替换或同路径语音 Mod 可能影响兼容性。
