# 玩家说明

## 安装角色包

1. 关闭游戏。
2. 打开《影之刃零》的安装目录，找到其中的 `ProjectPBZ` 文件夹。Steam 中可通过游戏属性中的已安装文件打开该目录。
3. 将压缩包中的 `ProjectPBZ` 文件夹合并到游戏根目录。
4. 确认以下三个文件处于同一目录，扩展名分别为 `.pak`、`.utoc` 和 `.ucas`。

```text
游戏根目录/
  ProjectPBZ/Content/Paks/~mods/HcxmmxLeMalin/
    zzz_HcxmmxLeMalin_0_2_0_dev_30_P.pak
    zzz_HcxmmxLeMalin_0_2_0_dev_30_P.utoc
    zzz_HcxmmxLeMalin_0_2_0_dev_30_P.ucas
```

启动游戏进入存档即可。此角色包通过游戏资源挂载生效。

更新本 Mod 时，先移走旧的 LeMalin 三件套，再放入新版。旧测试包可能直接位于 `~mods` 根目录，文件名包含 `HcxmmxLeMalin`、`Test` 或不同开发版本号。其他主角替换 Mod 也应先移出加载目录，避免同路径覆盖。

## F8 设置面板

面板固定在屏幕右侧，按 **F8** 打开或收起。点击保存设置后，下次启动继续使用上次选择。

| 选项 | 默认值与用途 |
| --- | --- |
| 服饰风格 | 白色，可切换最终黑色风格 |
| 兔耳模式 | 软耳，可切换竖耳 |
| 眼睛效果 | 宝石，可切换一般效果 |
| 背部武器 | 隐藏，包含长刀、刀鞘和腰后的工具小刀 |
| 背挂后移 | 25 cm，可调范围 0–40 cm |
| 自动表情 | 开启 |
| 自动眼神 | 开启 |

模型大小固定为本次采用的 125%，物理与渲染参数采用已确认的设置。面板的恢复默认按钮只重置本 Mod 设置。

## 可选战斗语音包

角色包和语音包可以分别安装。需要恶毒战斗语音时，关闭游戏，将语音压缩包中的 `ProjectPBZ` 同样合并到游戏根目录。

```text
游戏根目录/
  ProjectPBZ/Content/Paks/~mods/HcxmmxLeMalinVoice/
    zzz_HcxmmxLeMalinVoice_0_1_0_dev_3_P.pak
    zzz_HcxmmxLeMalinVoice_0_1_0_dev_3_P.utoc
    zzz_HcxmmxLeMalinVoice_0_1_0_dev_3_P.ucas
```

游戏需选择**中文语音**。语音包处理自机常用战斗发声，部分事件使用短语音，部分使用静音。剧情和对话继续使用原游戏语音。实际覆盖以本次核对的战斗事件范围为准，详见语音经验文档。

关闭语音替换时，退出游戏，移走 `HcxmmxLeMalinVoice` 文件夹，下次启动生效。

## 卸载与设置

关闭游戏后移走 `HcxmmxLeMalin` 文件夹即可卸载角色包，语音包需单独移走。卸载不会删除游戏存档。

玩家设置使用独立保存槽 `Hcxmmx_LeMalin_Player_v1`。需要排查旧设置时，可先在面板恢复默认并保存。

## 当前已知表现

- 使用原游戏动作，手掌与部分刀柄存在少量握持偏差。
- 辫子会与身体碰撞，武器与头发仍可能相交。背挂显隐与后移选项用于按个人观感选择。
- 强光场景下采用已接受的底色补偿，具体表现随游戏光照变化。
- 自动表情为定时变化，自动眼神为小幅游移，移动时回正。
- 新游戏版本、其他主角替换以及修改相同语音事件的 Mod 可能影响表现。

角色包对应已验收构建 `0.2.0-dev.30`，语音包对应 `0.1.0-dev.3`。后续反馈请一并说明游戏版本、安装的其他角色或语音 Mod，以及能观察到问题的动作或场景。
